1. Problem with PointNet

§01

PointNet's global max-pool aggregates all N points into a single 1024-D vector. This works for distinguishing chairs from planes, but it treats all points independently and discards all local geometric structure. The network cannot distinguish a flat surface from a curved one if the overall point distribution is similar.

Worse, real-world LiDAR scans suffer from non-uniform density: points cluster densely near the sensor and are sparse far away. A network trained on uniform samples generalises poorly under density variation because it has no mechanism to adapt its receptive field size to local density.

  • No local structure — max pool over all N points ignores neighbourhood relationships entirely; fine-grained shapes (bolts, hinges) are invisible.
  • Density blindness — a fixed global aggregation gives equal weight to dense near-field regions and sparse far-field regions.
  • No hierarchy — 2D CNNs build receptive fields progressively (edge → texture → part → object); PointNet jumps directly to global in one step.

2. Set Abstraction Layer

§02

PointNet++ introduces the Set Abstraction (SA) layer, which down-samples the point set while encoding rich local features. Each SA layer performs three sub-operations:

  • Farthest Point Sampling (FPS) — iteratively select the point furthest from all already-selected centroids. Produces M centroids that maximally cover the point cloud. More uniform than random sampling.
  • Ball Query — for each centroid, gather all points within radius r. Capped at K neighbours. Local neighbourhood is translation-invariant and density-adaptive.
  • PointNet mini-network — apply a small PointNet (shared MLP + max pool) to each local group of K neighbours. Outputs one d-dimensional feature vector per centroid. Result: N points → M points with richer features.
Three-level Set Abstraction hierarchy: each SA layer down-samples via FPS, groups via ball query, encodes with PointNet mini-net

3. MSG — Multi-Scale Grouping

§03

Non-uniform density breaks a single fixed radius: in a sparse region, a small radius finds zero neighbours; in a dense region, a large radius finds too many with insufficient local resolution. MSG runs multiple ball queries at different radii in parallel and concatenates the resulting feature vectors.

MSG: three ball queries at different radii, each with its own PointNet sub-network; features concatenated before propagation

MRG (Multi-Resolution Grouping) is a computationally cheaper alternative: instead of multiple radii at the same SA layer, concatenate features from two consecutive levels of the hierarchy — one computed from the raw local points, one propagated from the coarser level. When the local point set is dense, the raw-points branch dominates; when sparse, the coarser features take over. MRG avoids the cost of running multiple PointNets at the same level.

4. Feature Propagation for Segmentation

§04

Classification only needs the top-level global vector, but point-wise segmentation requires a feature at every original point. PointNet++ propagates features back down the hierarchy using interpolation + skip connections, similar to U-Net's decoder.

For each point at the finer level, its feature is computed as the inverse-distance-weighted average of its k nearest neighbours at the coarser level:

f(x) = Σ w_i · f(x_i) / Σ w_i,    w_i = 1 / dist(x, x_i)^p

The interpolated feature is then concatenated with the skip-connection feature from the encoder at the same level, and passed through a unit PointNet (per-point MLP) to refine. Stacking multiple FP layers recovers the full N-point resolution.

5. PyTorch Implementation

§05
pointnet2_sa.py — Set Abstraction layer with ball query grouping
import torch
import torch.nn as nn


def farthest_point_sample(xyz, npoint):
    # Iterative farthest point sampling. xyz: B×N×3, returns B×npoint indices.
    B, N, _ = xyz.shape
    centroids = torch.zeros(B, npoint, dtype=torch.long, device=xyz.device)
    distance  = torch.full((B, N), 1e10, device=xyz.device)
    farthest  = torch.randint(0, N, (B,), device=xyz.device)
    for i in range(npoint):
        centroids[:, i] = farthest
        centroid = xyz[torch.arange(B), farthest].unsqueeze(1)   # B×1×3
        dist = ((xyz - centroid) ** 2).sum(-1)                    # B×N
        distance = torch.min(distance, dist)
        farthest = distance.argmax(-1)
    return centroids


def ball_query(radius, nsample, xyz, new_xyz):
    # Find nsample neighbours within radius for each centroid.
    B, N, _ = xyz.shape
    M = new_xyz.shape[1]
    # pairwise distances B×M×N
    dist = ((new_xyz.unsqueeze(2) - xyz.unsqueeze(1)) ** 2).sum(-1)
    # mask points outside radius; sort and take first nsample
    idx = dist.argsort(-1)[..., :nsample]                         # B×M×nsample
    group_mask = dist.gather(-1, idx) > radius ** 2
    idx[group_mask] = idx[:, :, :1].expand_as(idx)[group_mask]   # pad with centroid
    return idx                                                     # B×M×nsample


class SetAbstraction(nn.Module):
    # Single Set Abstraction layer (SSG variant).

    def __init__(self, npoint, radius, nsample, in_ch, mlp_channels):
        super().__init__()
        self.npoint   = npoint
        self.radius   = radius
        self.nsample  = nsample
        layers = []
        last = in_ch + 3          # include relative xyz
        for out_ch in mlp_channels:
            layers += [nn.Conv2d(last, out_ch, 1),
                       nn.BatchNorm2d(out_ch), nn.ReLU()]
            last = out_ch
        self.mlp = nn.Sequential(*layers)
        self.out_ch = last

    def forward(self, xyz, features=None):
        # xyz: B×N×3, features: B×N×C or None → new_xyz: B×M×3, new_feat: B×M×out_ch
        B, N, _ = xyz.shape
        # 1. FPS
        idx      = farthest_point_sample(xyz, self.npoint)         # B×M
        new_xyz  = xyz[torch.arange(B).unsqueeze(1), idx]          # B×M×3
        # 2. Ball query
        grp_idx  = ball_query(self.radius, self.nsample, xyz, new_xyz)  # B×M×K
        grp_xyz  = xyz[torch.arange(B).view(B,1,1).expand_as(grp_idx),
                       grp_idx]                                     # B×M×K×3
        grp_xyz -= new_xyz.unsqueeze(2)                             # relative coords
        if features is not None:
            grp_feat = features[torch.arange(B).view(B,1,1).expand_as(grp_idx),
                                grp_idx]                            # B×M×K×C
            grp_in = torch.cat([grp_xyz, grp_feat], dim=-1)        # B×M×K×(3+C)
        else:
            grp_in = grp_xyz                                        # B×M×K×3
        # 3. PointNet mini-network
        grp_in  = grp_in.permute(0, 3, 2, 1)                      # B×(3+C)×K×M
        grp_out = self.mlp(grp_in)                                  # B×out_ch×K×M
        new_feat = grp_out.max(dim=2)[0].permute(0, 2, 1)         # B×M×out_ch
        return new_xyz, new_feat


# Quick test
if __name__ == "__main__":
    xyz  = torch.randn(4, 1024, 3)
    sa1  = SetAbstraction(npoint=512, radius=0.2, nsample=32,
                           in_ch=0, mlp_channels=[64, 64, 128])
    sa2  = SetAbstraction(npoint=128, radius=0.4, nsample=64,
                           in_ch=128, mlp_channels=[128, 128, 256])
    xyz1, f1 = sa1(xyz)
    xyz2, f2 = sa2(xyz1, f1)
    print(xyz1.shape, f1.shape)    # torch.Size([4, 512, 3]) torch.Size([4, 512, 128])
    print(xyz2.shape, f2.shape)    # torch.Size([4, 128, 3]) torch.Size([4, 128, 256])

7. Commentary

§07

PointNet++ is the natural follow-up to PointNet: it adds the hierarchical local-to-global processing that CNNs get "for free" from their convolutional structure. The Set Abstraction layer is conceptually a 3D analog of a convolutional layer — sample centroids, pool local neighbourhood, output a coarser representation — but adapted to irregular point sets.

The MSG density-handling is elegant but expensive: at each SA layer, you run K independent PointNet sub-networks. In practice many modern architectures (PointConv, KPConv, VoteNet) borrow the FPS + ball-query skeleton but replace the inner PointNet with cheaper operations.

Legacy: virtually every subsequent 3D detection or segmentation network (PointRCNN, VoteNet, 3DETR) uses PointNet++ as its backbone. FPS and ball-query have become standard primitives in 3D deep learning libraries (PyTorch3D, MinkowskiEngine).
