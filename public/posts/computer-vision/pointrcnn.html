1. Motivation

§01

Image-based 2D detectors generate proposals densely across the image plane because pixels are arranged uniformly. In 3D, a LiDAR point cloud is sparse and irregular — most of the volume is empty. Lifting 2D anchor grids into 3D (as in AVOD, PointPillars) wastes compute on empty voxels and requires hand-tuned anchor sizes per class.

PointRCNN's key insight: foreground points are already on object surfaces. Why not let each foreground point vote for its own 3D bounding box proposal? This bottom-up approach naturally focuses proposals where objects actually are.

2. Two-Stage Architecture

§02
PointRCNN two-stage pipeline: Stage 1 generates per-point proposals via bottom-up segmentation; Stage 2 refines using pooled local points

3. Stage 1 — Bottom-up Proposal Generation

§03

The PointNet++ backbone encodes each of the N input points into a per-point feature vector. A segmentation head then classifies each point as foreground (on an object) or background. Ground-truth supervision uses the 3D bounding box annotations: any point inside a GT box is foreground.

Each foreground point then predicts a 3D proposal anchored at itself, using bin-based encoding for x, z, and θ — and direct regression for y, h, w, l.

  • Focal Loss for segmentation — class imbalance is severe (foreground ≈ 5% of points). Focal loss down-weights easy background examples.
  • Bin-based x/z encoding — the x and z offsets from the point are divided into S discrete bins (e.g. S=12); the network predicts the bin index (cross-entropy) and a residual within the bin (L1). Avoids regression instability over the full range.
  • Bin-based angle θ — angle is divided into 12 bins of 30°; bin classification + residual. Handles the π-periodicity of 3D boxes cleanly.
  • Direct regression for y, h, w, l — height in the driving scenario is small range; width/length are regressed as log-scale residuals from mean priors.
Bin-based 3D box encoding: x and z ranges divided into S bins; predict bin index (classification) + sub-bin residual (regression)

4. Stage 2 — RCNN Refinement

§04

From Stage 1, the top-300 scored proposals (after NMS) are passed to Stage 2. For each proposal box, PointRCNN enlarges it slightly and collects all raw LiDAR points that fall inside. These points are transformed into a canonical coordinate frame (centred at the proposal, aligned with its heading), making the refinement task rotation-invariant.

The canonical point set is fed into another PointNet++ to predict the final box refinement (residuals on x,y,z,h,w,l,θ) and an IoU-based confidence score. This two-stage design — coarse proposals refined in canonical space — mirrors Faster R-CNN's region-of-interest pooling, but in 3D point cloud space.

5. PyTorch Implementation

§05
pointrcnn_head.py — Stage 1 foreground segmentation + proposal head
import torch
import torch.nn as nn
import torch.nn.functional as F


class ProposalHead(nn.Module):
    # Stage-1 head: per-point fg/bg classification + bin-based 3D box regression.
    # in_ch: per-point feature dimension from PointNet++ backbone
    # num_bins: S bins for x, z, theta encoding

    def __init__(self, in_ch=256, num_bins=12):
        super().__init__()
        self.num_bins = num_bins
        # Shared MLP before forking
        self.shared = nn.Sequential(
            nn.Conv1d(in_ch, 256, 1), nn.BatchNorm1d(256), nn.ReLU(),
            nn.Conv1d(256, 256, 1),   nn.BatchNorm1d(256), nn.ReLU(),
        )
        # Foreground / background binary classification
        self.seg_head = nn.Conv1d(256, 1, 1)

        # Box regression heads
        # x: num_bins cls + num_bins residual
        # z: num_bins cls + num_bins residual
        # theta: num_bins cls + num_bins residual
        # y, h, w, l: direct regression (4 values)
        self.x_bin_cls   = nn.Conv1d(256, num_bins, 1)
        self.x_bin_res   = nn.Conv1d(256, num_bins, 1)
        self.z_bin_cls   = nn.Conv1d(256, num_bins, 1)
        self.z_bin_res   = nn.Conv1d(256, num_bins, 1)
        self.theta_cls   = nn.Conv1d(256, num_bins, 1)
        self.theta_res   = nn.Conv1d(256, num_bins, 1)
        self.reg_head    = nn.Conv1d(256, 4, 1)   # y, h, w, l

    def forward(self, point_feat):
        # point_feat: B × C × N  (output from PointNet++ backbone)
        # Returns dict of raw predictions for loss computation.
        x = self.shared(point_feat)              # B × 256 × N
        seg_logits = self.seg_head(x).squeeze(1) # B × N  (fg/bg)

        preds = {
            'seg':      seg_logits,
            'x_bin':    self.x_bin_cls(x),       # B × S × N
            'x_res':    self.x_bin_res(x),
            'z_bin':    self.z_bin_cls(x),
            'z_res':    self.z_bin_res(x),
            'theta_bin':self.theta_cls(x),
            'theta_res':self.theta_res(x),
            'reg':      self.reg_head(x),         # B × 4 × N  (y,h,w,l)
        }
        return preds


def decode_proposals(preds, points_xyz, num_bins=12, search_range=3.0):
    # Convert per-point predictions to 3D proposals.
    # preds: output of ProposalHead.forward()
    # points_xyz: B × N × 3  (x, y, z of each point)
    # Returns: B × N × 7  (x, y, z, h, w, l, theta)
    B, N, _ = points_xyz.shape
    S = num_bins
    bin_size = 2 * search_range / S

    # x
    x_bin = preds['x_bin'].argmax(1)             # B × N
    x_res = preds['x_res'].gather(1, x_bin.unsqueeze(1)).squeeze(1)
    x = points_xyz[..., 0] + (x_bin.float() - S/2 + 0.5) * bin_size + x_res

    # z (similar)
    z_bin = preds['z_bin'].argmax(1)
    z_res = preds['z_res'].gather(1, z_bin.unsqueeze(1)).squeeze(1)
    z = points_xyz[..., 2] + (z_bin.float() - S/2 + 0.5) * bin_size + z_res

    # theta
    t_bin = preds['theta_bin'].argmax(1)
    t_res = preds['theta_res'].gather(1, t_bin.unsqueeze(1)).squeeze(1)
    import math
    theta = (t_bin.float() * (2*math.pi / S) - math.pi) + t_res

    reg = preds['reg']                            # B × 4 × N
    y   = points_xyz[..., 1] + reg[:, 0, :].permute(1,0)[...,0]  # simplification
    proposals = torch.stack([x, points_xyz[...,1], z,
                             reg[:,1,:].permute(1,0)[...,0],
                             reg[:,2,:].permute(1,0)[...,0],
                             reg[:,3,:].permute(1,0)[...,0], theta], dim=-1)
    return proposals   # B × N × 7

7. Commentary

§07

PointRCNN demonstrated that the two-stage detect-then-refine paradigm translates cleanly to 3D point clouds — you don't need a voxel grid to get high-quality 3D proposals. The bottom-up approach is elegant: by using every foreground point as a proposal anchor, the network generates dense, geometry-aware candidates for free as a side effect of segmentation.

The bin-based box encoding became widely adopted. Pure regression is fragile near angle discontinuities (e.g. 0 and 2π are the same orientation but far apart numerically); bin classification sidesteps this entirely. Later works (PV-RCNN, Voxel-RCNN) kept this encoding while upgrading the backbone.

Limitation: the Stage 1 foreground segmentation requires per-point 3D ground-truth labels at training time — expensive to annotate. In practice, 3D box annotations are enough to derive point-in-box labels automatically, so this is not a real constraint.
