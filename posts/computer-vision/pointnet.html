문제 정의 — Point Cloud의 3가지 어려움

3D 데이터는 Voxel, Mesh, Point Cloud 세 가지 표현이 있습니다. Voxel은 3D CNN 적용이 쉽지만 메모리가 O(n³)으로 폭발합니다. Point Cloud는 LiDAR·depth camera의 원본 출력이어서 빠르고 직관적이지만, 딥러닝에 그대로 적용하기 어려운 3가지 근본 문제가 있습니다:

  • Unordered (순서 없음): 점 1000개를 1000! 가지 순서로 배치해도 같은 형상. 어떤 순서로 입력해도 동일한 출력이 나와야 합니다.
  • Irregular (비균일 밀도): 가까운 영역은 점이 밀집하고 먼 영역은 희박합니다. 픽셀처럼 균일한 그리드 가정 불가.
  • Transformation variance: 물체를 회전·이동해도 같은 물체로 인식해야 합니다.

핵심 아이디어 — Symmetric Function + T-Net

해결책: 입력 순서에 무관한(symmetric) 집계 함수를 사용합니다. f({x₁,...,xₙ}) ≈ g(h(x₁),...,h(xₙ)) 여기서 g는 symmetric function입니다. 여러 후보(max, sum, mean) 중 Max Pooling이 가장 강력한 representation을 학습합니다. N개 점 각각에 shared MLP h를 적용하고 채널별 최댓값을 취하면 집합 크기에 무관한 1024차원 전역 특징이 됩니다.

변환 불변성은 T-Net(STN)으로 해결합니다. 입력 공간에 3×3, 특징 공간에 64×64 affine transform을 예측·적용해 정규 위치로 정렬합니다. T-Net 정규화 손실: L_reg = ‖I − AA^T‖²_F (orthogonality 강제).

Architecture

PointNet Pipeline — T-Net×2 정렬 → shared MLP → Global MaxPool → FC → Output

Segmentation branch: global feature(1024)와 per-point local feature(64)를 concat → 각 점마다 클래스 점수 예측. 전역 맥락과 지역 정보를 동시에 활용합니다.

💻 코드 — PointNet Classifier (PyTorch)

python — PointNet with T-Net and global max pooling
import torch, torch.nn as nn

class TNet(nn.Module):
    def __init__(self, k=3):
        super().__init__(); self.k = k
        self.mlp = nn.Sequential(
            nn.Conv1d(k,64,1), nn.BatchNorm1d(64), nn.ReLU(),
            nn.Conv1d(64,128,1), nn.BatchNorm1d(128), nn.ReLU(),
            nn.Conv1d(128,1024,1), nn.BatchNorm1d(1024), nn.ReLU())
        self.fc = nn.Sequential(
            nn.Linear(1024,512), nn.BatchNorm1d(512), nn.ReLU(),
            nn.Linear(512,256), nn.BatchNorm1d(256), nn.ReLU(),
            nn.Linear(256, k*k))
        nn.init.zeros_(self.fc[-1].weight)
        nn.init.eye_(self.fc[-1].bias.view(k,k))

    def forward(self, x):              # x: (B, k, N)
        feat = self.mlp(x).max(-1)[0]  # (B, 1024)
        return self.fc(feat).view(-1, self.k, self.k)

def ortho_loss(A):
    B,k,_ = A.shape
    I = torch.eye(k, device=A.device).unsqueeze(0).expand(B,-1,-1)
    return ((I - A @ A.transpose(1,2))**2).sum((1,2)).mean()

class PointNetCls(nn.Module):
    def __init__(self, n_cls=40):
        super().__init__()
        self.tnet3  = TNet(3);  self.tnet64 = TNet(64)
        self.mlp1 = nn.Sequential(nn.Conv1d(3,64,1), nn.BatchNorm1d(64), nn.ReLU(),
                                  nn.Conv1d(64,64,1), nn.BatchNorm1d(64), nn.ReLU())
        self.mlp2 = nn.Sequential(nn.Conv1d(64,128,1), nn.BatchNorm1d(128), nn.ReLU(),
                                  nn.Conv1d(128,1024,1), nn.BatchNorm1d(1024), nn.ReLU())
        self.head = nn.Sequential(nn.Linear(1024,512), nn.BatchNorm1d(512), nn.ReLU(),
                                  nn.Dropout(0.3), nn.Linear(512,256), nn.BatchNorm1d(256),
                                  nn.ReLU(), nn.Dropout(0.3), nn.Linear(256,n_cls))

    def forward(self, x):                          # x: (B,3,N)
        x = (self.tnet3(x) @ x.transpose(1,2)).transpose(1,2)
        x = self.mlp1(x)
        x = (self.tnet64(x) @ x.transpose(1,2)).transpose(1,2)
        feat = x
        g = self.mlp2(x).max(-1)[0]               # global (B,1024)
        return self.head(g), ortho_loss(self.tnet64(feat))

pts = torch.randn(4,3,1024)
logits, reg = PointNetCls()(pts)
print(logits.shape, reg.item())   # (4,40) scalar

💬 Commentary

PointNet은 point cloud를 딥러닝으로 직접 처리한 최초의 실용적 방법으로 3D vision의 패러다임을 바꿨습니다. "symmetric function으로 permutation invariance 해결"이라는 인사이트는 지금도 유효합니다.

그러나 한계가 명확합니다: 각 점을 독립적으로 처리해 인접 점들의 관계(local geometric structure)를 무시합니다. 비균일 밀도에도 취약합니다. 이 두 한계를 계층적 지역 학습으로 해결한 것이 PointNet++입니다. 그럼에도 PointNet은 오늘날 PointPillar, PointRCNN 등 실시간 3D detection 시스템의 기반 모듈로 여전히 살아있습니다.
